# Telco Customer Churn Data Engineering Project

## Project Overview
This project demonstrates an end-to-end Data Engineering workflow using Python, PostgreSQL, SQL, and Power BI.

## Project Workflow
1. Loaded the Telco Customer Churn dataset from a CSV file.
2. Cleaned and validated the data using Python and Pandas.
3. Handled missing values and corrected data types.
4. Loaded the cleaned dataset into PostgreSQL.
5. Queried the database using SQL.
6. Built an interactive Power BI dashboard connected to PostgreSQL.

## Technologies Used
- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- SQL
- Power BI
- GitHub

## Project Files

- `etl.py` → ETL pipeline
- `sql_queries.sql` → SQL queries used for analysis
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` → Dataset
