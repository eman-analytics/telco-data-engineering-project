# Customer Churn Predictor — updated demo

1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Ensure the dataset CSV is beside app.py.
4. Run `python -m pip install -r requirements.txt`
5. Run `python -m streamlit run app.py`

This version displays Accuracy, Precision, Recall, F1-score, a confusion matrix, and a detailed classification report from a held-out test set. It is a learning/demo project, not a production decision system.
